# HiFi

HiFi is a modern, privacy-focused open source music client built with Compose Multiplatform for Android and Desktop.

## Features
- Clean Google Material You (Material 3 Expressive) design
- Ad-free streaming powered by YouTube Music
- Background audio playback and local caching
- Synced lyrics with word-by-word animation
- 10-band equalizer and custom audio effects
- Seamless integration with Spotify Canvas & Last.fm
